# Asritha Portfolio

Responsive personal portfolio for Chirra Asritha.

## Files
- `index.html` — portfolio content
- `style.css` — responsive styling
- `script.js` — mobile menu and dark-mode toggle

## How to open
Extract the ZIP and double-click `index.html`, or open the folder in VS Code and use Live Server.

The profile section contains only the **9.2 CGPA** and **4 Projects** statistics. The **5 network security scenarios** detail remains inside the Insider Threat Detection project.
